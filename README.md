# PC Mode for Redmi Pad

Redmi Pad 2 Pro uchun moslashtirilgan Xiaomi PC Mode planshetda ish stoli, Start menyusi va pastki panel orqali ilovalarni ochish imkonini beradi. Loyiha Xiaomi PC Mode 12.1.208.5 asosida tayyorlangan.

## Sinov holati

v9 ish stoli Redmi Pad 2 Pro’da Android 16 va HyperOS 3 bilan sinovdan o‘tdi. Tasdiqlash oynasida **OK** tugmasi orqali ish stoliga kirish mumkin. Besh barmoq bilan chapga surib ochish funksiyasi tekshirilmoqda.

`src/` papkasida v9 uchun tiklangan Java manbalari joylashgan. To‘liq APK yig‘ish uchun asosiy APK va unga mos yig‘ish skriptlari ham kerak.
